# Destiny Article Style

This optional WordPress companion style preserves heading hierarchy, paragraph spacing, callouts, figures, and captions for posts sent by Destiny. It is scoped to the `.destiny-article` wrapper and does not restyle other posts or pages.

Install once per WordPress site:

1. Upload `destiny-article-style.zip` in **Plugins > Add New > Upload Plugin**.
2. Activate **Destiny Article Style**.
3. Preview a Destiny draft before publishing.

Destiny's publication verification remains responsible for content and media readiness. This plugin only normalizes presentation across themes such as Divi.
